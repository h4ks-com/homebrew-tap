# h4ks-com Homebrew tap

Homebrew formulas for h4ks-com projects, for macOS and Linux.

```
brew install h4ks-com/tap/kess
```

| Formula | What it is |
|---|---|
| [kess](https://github.com/h4ks-com/kess) | Chess on a glossy 3D board in your terminal, against a bot or online |
| [katnav](https://github.com/h4ks-com/katnav) | Web browser for the terminal, drawn with the kitty graphics protocol |

A workflow points each formula at its project's latest release every six
hours, and you can start it by hand from the Actions tab.
